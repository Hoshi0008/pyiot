# DSL 语法参考

`parser.dsl_parser` 使用一种简短的领域特定语言描述二进制帧结构。本节给出完整语法说明。

## 1. 类型段（基本字段）

单个字母表示字段宽度（大小写均可，内部统一转小写处理）：

| 字符 | 宽度（字节） | 说明 |
|---|---|---|
| `B` / `b` | 1 | 字节（byte） |
| `W` / `w` | 2 | 字（word） |
| `D` / `d` | 4 | 双字（double word） |
| `Q` / `q` | 8 | 四字（quad word） |

多字节字段按 `endian` 参数（默认大端）用 `int.from_bytes` 转成整数。

## 2. 重复计数 `{...}`

紧随类型字母之后，控制该字段匹配多少次（每匹配一次消耗一个字段宽度的字节）：

- `{n}`：n 为数字字面量，如 `B{4}` 匹配 4 个字节；
- `{name}`：n 取自定义变量的值，变量由 `assignments` 提供，如 `assignments=["n=raw[3]-1"]` 配合 `B{n}`；
- 省略 `{}` 等价于 `{1}`；
- 重复次数 ≤ 0 时，该字段的映射值为空列表 `[]`；
- **注意**：重复匹配时使用同一个字段名覆盖写入，最终只保留**最后一次**匹配的值。

## 3. 常量段 `(...)`

圆括号内为常量表达式，在 `raw` 与 `sum` 环境中求值：

- `(0x00, 0xff)`：含逗号，按元组求值，要求 `raw` 当前位置的连续字节依次等于 `0x00, 0xff`；
- `(0)`：不含逗号，单常量，要求当前位置的字节等于 `0`；
- 匹配失败则整体解析失败，返回 `None`；
- 匹配成功后对应字段的值为：多常量 → `list[int]`，单常量 → `int`。

## 4. 完整示例（main.py）

定义 `B(0,0xff)BBBB{n}B(0)`：

- `B` → 1 字节字段（preamble）；
- `(0,0xff)` → 匹配连续字节 `0x00 0xff`（帧头 start_code）；
- 三个 `B` → 三个单字节字段（len / lcs / tfi）；
- `B{n}` → n 个字节的数据字段（n 来自赋值 `n=raw[3]-1`）；
- `B(0)` → 匹配一个值为 `0` 的字节（dcs）。

## 5. 错误处理

| 情况 | 异常 |
|---|---|
| 类型字母不在 `b/w/d/q` 中 | `TypeError("Unknown type ...")` |
| 定义中出现未知字符 | `ValueError("Unknown character ...")` |
| `{...}` 内容以数字开头但不是纯数字（不能作为变量名） | `ValueError("... cannot as a variable name")` |
| `{name}` 引用了未定义的变量 | `KeyError`（`assignments_table[s]`） |
